W 走廊结构下界），本轮做一次**运输层结构调整**：把 C 型末班 f05 上的 S004-FOD-01

## 动机（第一性原理）

- f05（U07 末班，4926→6959.8 s）载 S005 2 箱 + S011 段 2 箱（S011-FOD、S004-FOD）；
  减掉 S004-FOD 后 f05 少飞 1 箱交接与载荷，返场 6959.8 → 6893.8 s。
- f20（U08，3595→5949 s）载 S003 4 箱 + S004-HYG，加 S004-FOD 后 56 kg，仍远低于
  C 型 80 kg 上限，返场 6015 s，不触及任何瓶颈。
- 该转移**不动 f11**（避免 EDF 排序扰动把 f09 挤到 U01 链尾——v24 实验 1 已验证
  f11 加箱会连锁致 W 尾段 6742/联合 7144）；**不动 f4/f22**（N 窗口结构不变）。
- 26 架次不变，避开 v19（27 架）与 v20（组合转移）的失败模式。
