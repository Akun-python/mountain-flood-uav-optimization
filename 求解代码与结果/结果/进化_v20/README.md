# 进化 v20 — P2 能耗最小化（完工 ≤6960 s）与中继安全筛查（实验记录）

在 v19 结论（P2 结构拆分不可落地为联合口径提升）基础上，本轮尝试**不动架次
结构**的 P2 能耗优化：① 同区货箱转移 + 机型换型（保持 26 架）；② "中继窗口
包含性"快速筛查（理论初判：窗口 ⊆ 官方窗口 ⇒ 联合无损）。两个方向均找到
P2 单口径改进，但**全部被端到端（联合完工最小化 SA）验证拒绝**，并修正了
一个不充分的方法学判据。结论进一步强化：**官方 26 架解是系统帕累托最优**。

## 实验 1：P2 能耗修复（转移 + 换型，26 架不变）

脚本：`实验/p2_energy26.py`。接受准则=能耗下降 ∧ 完工 ≤ 6960 s ∧ 零迟到
∧ 保持 26 架。找到**严格支配解：能耗 70.705→70.088 kWh（-0.617）、完工
6959.81→6927.14 s（-32.7）、26 架不变**。移动明细：S005-WAT-02 与
S005-HYG-01 f23→f5、S008-MED-01 f24→f6、S001-WAT-02 f34→f17、
S011-FOD-01 f5→f11、f11 A→B 换型。

**端到端（官方管线+SA 重寻偏移，联合完工最小化 SA 3000 迭代）：联合下界
7466.1 s（+206）、中继能耗 3.729 kWh（+0.312）**。原因：转移使 W 窗口扩至
[778,7102]（S005 箱并入最晚 C 型架次 f5 拉长 W 覆盖段）、E/N 提前
（[1100,…]/[5375,…]）——同 v19 的耦合机理。**不采纳。**

## 实验 2：中继安全换型筛查（窗口包含性判据 → 证伪）

脚本：`实验/p2_swap26.py`。理论初判（后被证伪）：若候选在官方偏移下每组
任务段 ⊆ 官方窗口（W [1078,6802]、E [1406,4074]、N [5894,6446]），则
官方偏移对该候选可行 ⇒ 联合 ≤ 7259.81、中继 ≤ 3.417 kWh。

结果：唯一窗口包含的降耗换型 = **f11（S011 直连区）A→B，-0.187 kWh**，
换型后中继采样数与窗口段与官方完全一致（need-relay 1386、covW 1084 相同）。

**证伪（关键方法学教训）**：该候选套用官方偏移后运输完工跳到 **8067 s**
（B 型变慢 → EDF 就绪链重排 → 临界路径上移）；重寻偏移（联合完工最小化
SA）联合下界 = **7406.1 s（+146）、中继 3.711 kWh（+0.294）**（f11 由 A
机链转入 B 机链成为瓶颈）。**结论：窗口包含性是必要非充分条件——偏移是
全局释放量，任何架次剖面变化都会经 EDF 调度链传导，唯有完整联合最小化
SA 端到端验证可定罪/放行。**

## 综合结论（v19+v20，四个候选族系全部拒绝）

| 候选族系 | P2 单口径 | 联合口径（最小化 SA） | 裁决 |
|---|---|---|---|
| 27 架拆分（v19） | 6896.51 s / 70.16 kWh | 7838.8 s / 3.742 kWh | 拒绝 |
| 28 架拆分（v19） | 6836.51 s / 72.94 kWh | 更差 | 拒绝 |
| 26 架转移+换型（v20） | 6927.14 s / 70.09 kWh | 7466.1 s / 3.729 kWh | 拒绝 |
| 26 架 f11 A→B（v20） | 6959.81 s / 70.52 kWh | 7406.1 s / 3.711 kWh | 拒绝 |

**官方 26 架解（6959.81 s / 70.71 kWh；联合 7260 s / 中继 3.417 kWh）在
P2、联合完工、中继能耗三口径下经多框架独立搜索（Tabu 强化、破坏-重建
混合、能量修复、窗口筛查、联合最小化 SA）确认为系统帕累托最优。**
