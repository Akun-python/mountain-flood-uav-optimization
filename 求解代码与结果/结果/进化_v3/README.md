本目录归档"算法进化"第 3 版的可复现成果：以多算法对比冠军（Tabu 搜索）优化的运输
方案为输入，接入既有问题三"运输 + 中继小区协调"管线（`代码/p3_co2.py`）得到的联合结果。

## 复现命令

```bash

# 3) 问题三联合调度（读 p2_results.json）

```

## 结论

- **算法方向充分扩展**：同一优化问题用五种元启发式框架（模拟退火、遗传算法、自适应
  大邻域搜索、禁忌搜索、GRASP）在同一算力口径下对比，禁忌搜索（Tabu）胜出。
- 禁忌搜索把架次数从 33 → 21、完工时间 8651 → 8337 s、能耗 86.82 → 68.06 kWh
  （对问题二），并把运输能耗较综合报告再显著下调。
- 剩余工作（后续版本）：修复 1 个未覆盖中继采样点（中继坐标微移或货箱再重排），并把
  进化方案落到论文正文与提交表格。
