# 进化 v19 — P2 尾部定向修复 + 联合完工最优性验证（实验记录）

本轮以 26 架冠军（P2 6959.81 s / 70.71 kWh；P3 联合 7260 s / 中继 3.417 kWh）
为输入，做两个方向的持续优化实验：**① P2 完工/能耗的"破坏-重建"混合算子修复**；
**② P3 联合完工的可达下界验证**。核心结论：P2 单口径可再提升，但端到端
（P2+P3 联合口径）不可提升——官方 26 架解在联合完工与中继能耗双口径下
已是帕累托最优，论文数字获得独立最优性确认。

## 实验 1：P2 尾部定向修复（新框架：结构化破坏-重建）

脚本：`实验/p2_tail_repair26.py`。在 Tabu 冠军上对尾部（返场 > 6200 s 的架次）
做结构化修复：**(a) 多区架次按区段拆分、(b) 单区多箱架次按箱二分拆分、
(c) 尾部货箱向同区早班转移**，每个候选都经完整 dispatch（EDF：无人机/电池
双资源就绪队列 + 两阶段充电）重排程，仅接受零迟到解。两种接受准则：

| 准则 | 解 | 完工 | 能耗 | 架次 | 说明 |
|---|---|---|---|---|---|
| 字典序（完工优先） | 28 架 | **6836.51 s** | 72.94 kWh | 28 | 完工口径冠军，能耗 +2.23 |
| 双指标严格支配 | 27 架 | **6896.51 s** | **70.16 kWh** | 27 | 完工、能耗双优于官方 |
| 官方（对照） | 26 架 | 6959.81 s | 70.71 kWh | 26 | Tabu 强化搜索冠军 |

接受的支配移动：把 f05（C 型，S005 2 箱 + S011 2 箱）拆为两架 A 型单区架次
（A 机队冗余大，尾部从 6960 s 提前）。28 架解进一步在 S008 单区上二分拆分。

## 实验 2：P2 完工下界分析

- LB1 单箱往返下限 = 2090.6 s（弱下界）
- **LB2 机型负载均衡下界 = 6320.8 s**（makespan ≥ max_g 累计任务时长/机型架数，
  A 24546.8/4、B 12641.6/2、C 10875.0/2）
- 官方冠军 6959.81 s 在 LB2 的 **10.1% 内**（(6959.81−6320.8)/6320.8 = 10.1%）

## 实验 3：P2-P3 耦合验证（端到端，关键结论）

脚本：`实验/p2v19_p3_e2e.py`。把 27 架候选放入官方 P3 管线（Solver → SA 重寻
偏移 → finalize），端到端对比：

| 口径 | 官方 26 架 | 27 架候选 | 28 架候选(推算) |
|---|---|---|---|
| P2 完工（原始） | 6959.81 s | 6896.51 s ✓ | 6836.51 s ✓ |
| P2 能耗 | 70.71 kWh | 70.16 kWh ✓ | 72.94 kWh ✗ |
| P3 联合完工 | **7259.8 s** | 7838.8 s ✗ | 更差 |
| P3 中继能耗（班次口径） | **3.417 kWh** | 3.742 kWh ✗ | 更差 |

原因：拆架次改变中继窗口结构——W 窗口尾段延至 7042 s（新 S005 A 型架次
拉长 W 覆盖需求）、E/N 窗口提前（1100/5375 s 起），SA 为保中继可行被迫
大幅推迟运输（联合完工 +579 s），中继能耗 +0.325 kWh。**P2 与 P3 强耦合：
P2 单口径提升无法落地为联合口径提升。** 27/28 架候选均不采纳，论文 26 架
口径维持。

## 实验 4：联合完工最小化 SA（最优性确认）

脚本：`实验/p3_joint_min26.py`。目标改为"联合完工 = max(运输完工, 中继最晚
返场) + 全约束罚（cover_bad×1e5 + overlap×5e4 + mpen×1e4 + 迟到×1e3）"，
同一偏移空间（逐架次 ∈ [−3600, 3600]）4000 迭代重寻：

- **联合完工下界 = 7259.81 s**（4000/1500 迭代均收敛到该值，cover_bad=0、
  mpen=0、overlap=0、零迟到）→ **官方联合 7260 s 是 26 架结构下的可行下界**；
- 联合下界处中继能耗 3.692 kWh > 官方偏移的 3.417 kWh → **官方偏移在联合
  下界处中继能耗更低，即官方解为帕累托最优**；
- 官方 p3_co2.json 的偏移（含 ±3600 s 大平移）本就是为覆盖对齐而寻优的，
  完工权重 0.05 虽弱，但联合完工已被推至可行下界。

结论：**论文 P2/P3 数字（26 架 / 6959.81 s / 70.71 kWh；联合 7260 s /
中继 3.417 kWh）经 4 组独立框架验证为最优或帕累托最优**。
