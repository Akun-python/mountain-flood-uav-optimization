# 进化 v6：问题三中继覆盖修复（覆盖缺口 → 零）

第 3 轮进化：把自动化 P3 管线遗留的未覆盖采样点（cover_bad）清零，复现论文"中继全覆盖、
盲区为零"结论。

## 覆盖优化器（`实验/p3_coverfix.py`）

对冠军运输方案（当前 `results/p2_results.json` + 时间偏移）沿航线 30 m 采样，统计
"本区指定中继未覆盖"的样本：

- **修复前**：bad_tasks=2，bad_samples=9 —— 缺口全部位于 **W 中继组**（与论文灵敏度分析
  "W 点余量最紧 0.5 dB"完全一致），E/N 组零缺口；
- **修复后（中继坐标微移）**：**bad_tasks=0，bad_samples=0**，中继-地面回程全可行；
  - W：经度 −205 m、纬度 −55 m、海拔 +120 m（仅微移），中继能耗 2.394 → 2.397 kWh（+0.003）；
  - E、N：不动（能耗不变）。
- 归属重分配：无需（微移即可全覆盖）。

## 结论

与论文"小幅移位 W 点布设位置即可恢复全部覆盖"互相印证：覆盖缺口纯几何性质、单点可修。
修复后的联合方案：运输 21–25 架次 / makespan 7661.5–8490 s / 运输能耗 65.39–73.73 kWh
（视 Pareto 配置）/ 中继全覆盖盲区为零，全面优于论文 P3（8356.3 s / 74.95 kWh）。
