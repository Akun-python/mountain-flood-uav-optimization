**发现 2 处可改进**：
1. **中继悬停位置固定 3 个（W/E/N）**——题意允许悬停于 DEM 范围内任意位置。固定 3 位置是"简化约束"，可能放大中继窗口重叠与 N/E 冲突（联合完工拖尾与此相关）——**真正可"跳出框架"的 P3 优化点（位置自由化）**。
2. **`bat_end = start+prep+flight_time` 未加 handover**——电池可充电时刻偏早（宽容方向，不违约）；严谨应为 `start+duration`。

**结论**：严格口径（投递区=箱属区、捎带非法）与题意一致，不构成对 26 架冠军否定的误杀；对方 23 架/5694s/67.14kWh 若成立需逐级更。
