2. **严格口径基线 = 28 架 / 8153.2s / 80.31kWh**（并行线最新工作区 p2_results.json，区一致 hard True）

3. **本轮压缩结果（区一致）**：

4. **23 架方向（mk_hyper 7722.1s/67.48kWh）不可行**：依赖 33 箱捎带（区混乱遍布 22 架次），严格口径 hard False；且 23 架完工本就 >26 架冠军。
