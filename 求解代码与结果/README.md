## 运行方式（最新冠军管线）

程序的数据路径为相对路径，需在原始工作区
`华为杯latex模板/` 下运行（该目录下含
`第二十三届中国研究生数学建模竞赛 - 中文题目/中文题目/D题/数据`）：

```bash
# 1. 五族算法公平对比基准（SA/GA/ALNS/Tabu/GRASP，墙钟预算公平对比）
python -X utf8 求解代码与结果/实验/benchmark.py --seconds 60 --seeds 7,11,13

# 2. 强化冠军搜索并导出冠军配置到 p2_results.json
python -X utf8 求解代码与结果/实验/champion_search.py --seconds 600 --seeds 7,11,13 --restarts 2 --export

# 3. 运输-中继联合调度（读取 p2_results.json）
python -X utf8 求解代码与结果/代码/p3_co2.py

# 4. 中继覆盖核验与接入链路余量统计
python -X utf8 求解代码与结果/实验/p3_coverfix.py
python -X utf8 求解代码与结果/实验/margin_stats.py

# 5. 导出结果提交模板
python -X utf8 求解代码与结果/代码/export_excel.py
```

## 当前冠军结果（进化 v25，论文口径）

- 问题二（p2_results.json）：28 架次（A×12、B×8、C×8），8 架无人机，14 组电池；
  makespan 7394.9 s，总能耗 83.12 kWh，三档时限零违反、加权迟到为零；
  **严格口径**：每个货箱投递时刻所归属服务区与其箱号前缀一致（区一致，
  hard 检查零跨区），电池复用前按返场时刻满充（附录 2 口径）。
  较原遗传算法均衡方案（24 架次 / 8342.1 s / 77.31 kWh）完工提前约 16 min（11.4%）、
  能耗增加约 5.8 kWh（完工优先方向）。
- 问题三（p3_co2.json）：28 架次区一致方案沿航线 30 m 步长审核得到 1762 个
  需中继采样点，初始布设即全覆盖（W/E/N 三点）。中继按时间分片四时段保障：
  W1 [1058,7453] s（2.184 kWh）、W2 [8605,9072] s（0.372 kWh）、
  E [1060,5498] s（1.549 kWh）、N [6565,7308] s（0.488 kWh），中继合计 4.59 kWh；
  W 单班超能源预算拆为两班。为对齐 N 点窗口，S004 架次后移约 2100 s，
  偏移后运输完工 9473 s；中继 W2 最晚返场 9491 s = 联合完工（约 158.2 min）；
  零迟到、零盲区（cover_bad=0）、东转北转场等待 58 s（machine_pen=58）。
- 问题四（p4_results.json）：v25 冠军的 8 组跨区架次约束下，地理片区分区
  违反"同架次同组"规则，改为满足完整性的 K3（11/3/1 区）与 K2（13/2 区）分区；
  独立配置均超库存（K2 需 A6B5C5/bat22/relay7/comp12，K3 需 A8B5C5/bat24/relay8/comp14），
  结论为分区用于组织、资源集中池化（8 机/14 电池/2 中继恰好满足库存）。
- 独立校验：80 箱无重复无缺失；无不可行架次；硬时限零违反；通信盲区为零
  （1771 直连 + 1762 需中继，30 m 步长逐点判定）。
- 合规评审：附录 2/3 公式逐条核对 20/20 通过（`评审/评审报告_v25合规性.md`）；
  电池充电起点口径修复（`代码/p2_solve.py`，修复后 0 违规、指标不变）。
- 版本归档：问题二/三/四持续优化实验见 `结果/进化_v3 … 进化_v24/README.md`
  与 `结果/进化_v25/`（电池口径验证、P3 修复版重搜、P4 v25 分区重算、
  本表对应结果 `p3v25_final.json`/`p3v25_search2_best.json`/`p4_partition_compare26.json`）。
