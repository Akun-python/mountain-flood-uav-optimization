## 运行方式（最新冠军管线）

程序的数据路径为相对路径，需在原始工作区
`华为杯latex模板/` 下运行（该目录下含
`第二十三届中国研究生数学建模竞赛 - 中文题目/中文题目/D题/数据`）：

```bash
# 1. 五族算法公平对比基准（SA/GA/ALNS/Tabu/GRASP，墙钟预算公平对比）
python -X utf8 求解代码与结果/实验/benchmark.py --seconds 60 --seeds 7,11,13

# 2. 强化冠军搜索并导出冠军配置到 p2_results.json
python -X utf8 求解代码与结果/实验/champion_search.py --seconds 600 --seeds 7,11,13 --restarts 2 --export

# 3. 运输-中继联合调度（读取 p2_results.json）
python -X utf8 求解代码与结果/代码/p3_co2.py

# 4. 中继覆盖核验与接入链路余量统计
python -X utf8 求解代码与结果/实验/p3_coverfix.py
python -X utf8 求解代码与结果/实验/margin_stats.py

# 5. 导出结果提交模板
python -X utf8 求解代码与结果/代码/export_excel.py
```

## 当前冠军结果（进化 v42 定稿：25 架，论文口径）

- 问题二（p2_results.json）：25 架次（A×11、B×8、C×6），8 架无人机，14 组电池；
  makespan 7112.8 s，总能耗 70.28 kWh，三档时限零违反、加权迟到为零；
  **严格口径**：每个货箱投递时刻所归属服务区与其箱号前缀一致（区一致，
  hard 检查零跨区），电池复用前按返场时刻满充（附录 2 口径）。
  较原遗传算法均衡方案（24 架次 / 8342.1 s / 77.31 kWh）完工提前约 20.5 min（14.7%）、
  能耗降低约 7.0 kWh（9.1%）。由 29 架冠军（7112.8/74.56）做小幅参数搜索：
  tabu 续搜得到 28 架/7058.3/76.58（完工更优）等 Pareto 点，最终以合法顺路合并把
  同片区的架次并入 25 架（C 型 S006+S007、S008+S005、A 型 S011+S005 等），
  同完工下能耗降至 70.28。

- 问题三（p3_co2.json）：25 架次区一致方案沿航线 30 m 步长审核得到 1394 个
  需中继采样点（W 1029 / E 290 / N 75），初始布设即全覆盖（W/E/N 三点）。
  中继按时间分片三时段保障：W [716,6777] s（2.082 kWh）、E [760,3354] s（0.986 kWh）、
  N [3409,4135] s（0.483 kWh），中继合计 3.550 kWh，各班均低于单架次能源预算；
  25 架次时刻天然与中继窗口相容，运输无需平移，联合完工 = 运输完工 7112.8 s
  （约 118.5 min），中继约束引入的完工代价为零；零迟到、零盲区（cover_bad=0）。

- 问题四（p4_results.json）：25 架次多区架次均落在同一覆盖片区（无跨片区同组约束），
  采用自然分区（K3：西/北 10 区 + 东 4 区 + S004；K2：西/北 10 区加 S004 + 东 4 区）；
  独立配置均超库存（K2 需 A6B5C3/bat19/relay5/comp7，K3 需 A6B5C5/bat21/relay7/comp9），
  结论为分区用于组织、资源集中池化（8 机/14 电池/2 架中继分片恰好满足库存）。

- 独立校验：80 箱无重复无缺失；无不可行架次；硬时限零违反；通信盲区为零
  （需中继采样 1394 个，30 m 步长逐点判定）。

- 合规评审：25 架冠军经官方严格管线复核 8/8 通过（`结果/进化_v42/review_apply25_authoritative.json`）；
  电池充电起点口径修复（`代码/p2_solve.py`，修复版语义复核 0 违规）；
  v25（28 架 / 7394.9 s / 83.12 kWh）合规评审 20/20 见 `评审/评审报告_v25合规性.md`。

- 版本归档：问题二/三/四持续优化实验见 `结果/进化_v3 … 进化_v41/README.md`
  与 `结果/进化_v42/`（25 架 P3 基线权威 `p3v42_final.json`、P4 自然分区
  `p4_partition_compare26.json`、合规复核 `v42_compliance_review.json`）。

## 关键版本说明

论文最终采用进化 v42 定稿完工冠军口径（25 架 / 7112.8 s（118.5 min）/ 70.28 kWh +
中继三时段联合，联合完工 7112.8 s），源自 29 架冠军（v42 并行线）的
装配密度搜索及合法顺路合并，较 v42 早期（7112.8/74.56）在完工不变前提下能耗

总能耗 74.95 kWh），保留仅用于对照复现；v25 及更早冠军（28 架 / 7394.9 / 83.12 等）
的完整实验记录见 `结果/进化_v*/README.md`。各版本说明见各目录 README。
